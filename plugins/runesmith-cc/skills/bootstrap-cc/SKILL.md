# Bootstrap CC (renamed)

`bootstrap-cc` is now **`runesmith-cc:head`**. To set up a whole project, run `runesmith-workspace:init`, which calls `head` for code projects. To add a repo or refresh an existing head, run the `head` skill in this plugin. This pointer is removed in the next release.
