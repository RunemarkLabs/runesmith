Setting up a project at {COMPANY} end to end, against the Atlassian site at {SITE}.

1. Install the plugins

text

2. Run init

In the project's Claude Project, with the project folder connected, run /runesmith-workspace:init. It drafts what the project is, asks whether it holds code and whether it uses Jira, shows every change, and applies it on your approval. For a code project it builds the Claude Code head: the builder's rules, settings, skills, the comms folder, and the repo with dev, qa and beta branches.

3. Credentials

Keys live where the thing that uses them runs, and never inside a repo folder. Init writes empty, labeled lines and tells you which file and key to fill. Never paste a token into chat.

The Claude Code head's .credentialsCC_ATLASSIAN_API_EMAIL, CC_ATLASSIAN_API_TOKEN (read-only), ATLASSIAN_BOARD_IDClaude Code, when Jira is on

Atlassian tokens: id.atlassian.com/manage-profile/security/api-tokens. GitHub tokens: github.com/settings/personal-access-tokens (fine-grained; contents read and write, issues read, and administration write to create repos and protect branches).

4. Turn on Jira (optional)

Run /runesmith-sprint:enable (or answer yes in init). It records the project key {PROJECT_KEY}, the board and the space {SPACE_KEY}, and deploys Claude Code's read-only Jira skills. Check with /runesmith-jira:project-status.

5. Install the guardrail (once per machine)

Run /runesmith-cc:guardrail and then the one command it gives you. Every Claude Code session on the machine then stays inside its own project.

6. First piece of work

  1. /runesmith-core:plan captures the change.
  2. /runesmith-sprint:task writes the task and gives you a /goal line.
  3. Paste the line into Claude Code, opened in the project's head folder.
  4. When Claude Code prints its banner, say "check comms" to the planner.
  5. Say "promote to qa" when the build is ready, then run the QA checklist page.

7. Common gotchas

  • Email and token from different accounts: 401.
  • A page lands in the wrong space: lookups must carry space-id={SPACE_ID}.
  • Updating a page without the next version number: 409. The skills handle it.
