{COMPANY} - AIOPS FAQ

How do I start a new project?

Connect the project folder to a Claude Project and run /runesmith-workspace:init.

Claude Code finished. What now?

Say "check comms" to the planner. It verifies the replies, archives finished work, tells you what needs you, and gives the next goal line.

Claude Code stopped with a question.

It's listed under "Needs you" in the banner. Check comms; the planner shows it to you as a choice, writes the answer, and gives the goal line that resumes the work.

How do I get a build to QA?

Say "promote to qa". Claude Code runs the full suite against dev first. The planner then gives you the QA checklist page.

A checklist item failed.

Mark it failed and describe what you saw. It becomes a fix task; Claude Code opens the GitHub issue.

Why does a page publish fail with 400?

Confluence Cloud doesn't accept markdown bodies. The skills convert to storage format first.

Why does a page update return 409?

The version number was stale. Read the page, then send the next version number. The skills do this.

Why does a Jira create fail about assignee.name?

Jira Cloud needs an account id. Look it up with GET /rest/api/3/user/search.

Why doesn't /rest/api/3/search work?

It was retired. Use POST /rest/api/3/search/jql.

Can the skills create a Confluence space?

No. Create the space in Confluence first, then run the skills against it.

How do I find a custom field id?

GET /rest/api/3/field lists every field. Store the id in .credentials, for example ATLASSIAN_BUG_SEVERITY_FIELD.

Where do I get help?

Run /runesmith-devtools:help, or read the marketplace README.
